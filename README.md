# 26 Locks

An illustrated, sourced atlas of Jin Shin Jyutsu: the 26 Safety Energy Locks, the depths, flows, fingers and organ clock.
Every claim traces to a source key, and Mary Burmeister's books carry the most weight.

Astro, static output, served at `localmeridian.net/26locks/`. See [DEPLOY.md](DEPLOY.md).

This repository holds the published site only. The research notes it was curated from are kept elsewhere, so code
comments that mention `research/` point to files that aren't here.

## Commands

Run from this folder:

| Command | What it does |
|---|---|
| `npm run dev` | Dev server at `localhost:4321/26locks/` |
| `npm run build` | Merges sources, audits them, builds to `dist/26locks/`, checks internal links |
| `npm run preview` | Serves the build |
| `npm run audit` | Checks claims and sources; `audit:links` also checks external links |


## Rules for the content

- Every claim has a source, and opinions are attributed to whoever holds them. No medical claims.
- Write "Jin Shin Jyutsu" in full, never "Jin Shin". British spelling.
- Paraphrase with page citations. Don't copy long passages, and never save scans.
